# Linux Administration Script

A simple interactive Bash script for basic Linux administration tasks.

## Features

- Create users with a home directory and Bash shell.
- Check whether a user already exists.
- List running processes.
- Terminate processes by name.
- Install packages using APT.

## Requirements

- Debian or Ubuntu with Bash and APT.
- Sudo permissions for user creation and package installation.

## Usage

```bash
bash system_administration.sh
```

Select an option from the menu and follow the prompts.
